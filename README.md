# BulsAndCowsGame
# Быки и коровы (Qt, C++)

Расчетно-графическая работа №3.  
Игра «Быки и коровы», реализованная на C++ с использованием Qt.

## Описание

Компьютер загадывает четырехзначное число без повторяющихся цифр.  
Игрок должен угадать это число за минимальное количество попыток.

После каждой попытки выводится результат:

- Быки — цифры на правильных местах  
- Коровы — цифры есть, но стоят не на своих местах  

## Возможности

- новая игра  
- ввод числа с проверкой  
- подсчет быков и коров  
- таблица попыток  
- таблица рекордов (топ-10)  
- сохранение результатов в файл  
- ввод имени игрока  
- очистка рекордов  
- кнопка показа ответа (для отладки)

## Правила

1. Загаданное число — 4 цифры без повторений  
2. Число не начинается с 0  
3. Игрок вводит варианты  
4. Программа показывает быков и коров  
5. Игра заканчивается при угадывании числа

## Технологии

- C++20  
- Qt 6 (Widgets)  
- CMake  
- CLion  

## Сборка

Установить Qt:


brew install qt


Запустить через CLion или CMake.

Если нужно указать путь к Qt:


-DCMAKE_PREFIX_PATH=/opt/homebrew/opt/qt


## Формат рекордов

Файл `records.txt`:


попытки;имя


Пример:


7;Вова
10;Алексей
15;Игрок


## Особенности

- число генерируется случайно  
- без повторяющихся цифр  
- хранится максимум 10 рекордов  
- рекорды сортируются по попыткам
